# Marquisa — Design system fixo (referência: painel v3)

Usar **idêntico** em todas as páginas do mockup. Não inventar novo estilo por tela.

## Shell (sempre igual)

- **Largura:** desktop 1440px, muito espaço em branco entre blocos (não apertar).
- **Header (carvão escuro):**
  - Esquerda: emblema asa verde em círculo + **MARQUISA** branco + **PAINEL DO AERONAUTA** verde pequeno.
  - Centro: relógio **22:03:12 Z** grande, monospace, halo verde fosforo.
  - Direita: tagline curta OU botões da página (Entrar / Criar conta), **mesma altura de barra**.
- **Fundo da página:** cinza claro frio (painel de instrumentos).
- **Cards:** retângulos cinza claro, cantos arredondados, **4 parafusos nos cantos**.
- **Verde primário:** CTAs e destaques (#2d8a4e aprox.).
- **Rodapé (carvão):** ícones + rótulos — PAINEL · NOTAM · CARTA AERONÁUTICA · PLANO DE VOO · DOCUMENTOS · caixa **VOE SEGURO. VOE PREPARADO.**

## Dashboard (conteúdo central)

Três colunas iguais: METAR/TAF | BRIEFING DE ROTA | SIMULADOS (como referência visual original).

## Demais páginas (só troca o miolo)

- Mesmo header + mesmo rodapé.
- Centro: 1 ou 2 painéis com parafusos (formulário, lista, prova, texto legal).
- **Nunca:** novo layout, poster, aquarela, abas diferentes, header claro, sem UTC.
